# Kata: Meme Generator

In dieser Kata baust du mit deinem KI-Agenten einen kleinen Service, der Memes erzeugt. Was du baust, ist zweitrangig. Es geht darum, wie du mit dem Agenten arbeitest.

- [`brief.md`](brief.md): die Aufgabe
- [`participant-guide.md`](participant-guide.md): Regeln und Ablauf

Arbeite in deinem eigenen Fork, zum Beispiel in diesem Ordner.
