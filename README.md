## Abgabe

Dein Stand bleibt im Browser gespeichert. Am Ende lädst du auf der Seite deine Antwortdatei herunter (`antworten-trail-N-<kennung>.json`) und lädst sie über den [Upload-Link](https://kein.tropfenderkessel.de/index.php/s/gswbPWzDmQPF7wS) hoch. Zum Nachbessern einfach neu herunterladen und noch einmal hochladen.
